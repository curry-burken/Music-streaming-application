<h1>A music streaming application made with the help of React and Tailwind CSS</h1>
<h3>The application has a Home Page containing a Navbar, Sidebar, music album/biggest hit catalog and Player controls. It also has an individual page for each Playlist Album. The music is being streamed from locally stored mp3 files.</h3>
